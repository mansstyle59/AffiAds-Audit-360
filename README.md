# AffiAds Audit 360°

Application web autonome et responsive pour réaliser des audits manuels de restaurants et commerces : fiche Google, site web, réseaux sociaux, réputation, concurrence et tests de découverte dans les assistants IA.

## Démarrage

Ouvrir `index.html` dans un navigateur. Pas de dépendance, compte API ou serveur requis.

## Fonctions

- Fiche client : identité, ville, date, site, lien Maps, note et nombre d'avis si connus.
- Checklist de 28+ points répartis en cinq catégories.
- Marquage des points vérifiés et des points à améliorer.
- Score indicatif calculé sur les contrôles renseignés (il ne représente pas un classement Google).
- Priorités, notes, sauvegarde locale dans le navigateur.
- Rapport prêt à imprimer ou à enregistrer en PDF depuis le navigateur.
- Liens directs vers des outils publics de vérification.

## Limites importantes

Cette version n'extrait pas automatiquement les données de Google, Meta, les annuaires ou les assistants IA. Les mesures privées demandent les accès du propriétaire. Les vérifications de présence dans les assistants IA sont manuelles. Aucune recommandation ou position Google n'est garantie.
