Recherche publique sur le commerce

Prépare des recherches ciblées à partir du commerce, de sa ville et de son site. Chaque lien ouvre les résultats réels du moteur choisi : l’application ne prétend pas avoir lu les pages tant que tu ne les as pas vérifiées.

Important : les positions Google varient selon la ville, l’appareil et la personne. Ces recherches publiques ne donnent pas à elles seules un classement fiable. Pour mesurer les performances réelles, il faut accéder à Google Search Console, à la fiche Google Business Profile ou à une API de données autorisée.

Comment exploiter les résultats

1. Visibilité localeRecherche le nom + la ville, puis le service + la ville. Note les concurrents visibles et les informations manquantes.
2. Mots-clés et intentionTeste plusieurs formulations utilisées par les clients : service, quartier, prix, réservation et besoins précis.
3. RéputationCompare les avis récents, les points positifs qui reviennent et les objections non traitées.
4. Présence sur les assistants IATeste les mêmes questions dans les assistants disponibles et note la réponse, la date et les sources citées. Une réponse ponctuelle n’est pas une garantie de visibilité.

Mesurer la visibilité sur les IA

Teste la même question dans chaque assistant, puis enregistre la réponse observée. Cela construit une mesure reproductible par question et par date, pas un classement universel permanent.

Limite importante : les assistants ne fournissent pas tous une API publique permettant de mesurer automatiquement les réponses des comptes utilisateurs. AFFIADS ne peut donc pas prétendre interroger « toutes les IA » ni garantir un classement fixe. Les tests enregistrés indiquent exactement l’assistant, la question, la date et le résultat constaté.

Campagne de visibilité IA

Crée une série de questions reproductibles sur un commerce. AFFIADS prépare les tests et compare les résultats que tu observes dans les assistants ; la page n’interroge pas leurs comptes privés en arrière-plan.

Comment tester : ouvre chaque assistant, pose la question indiquée, observe s’il cite le commerce et les concurrents, puis utilise « Enregistrer le résultat ». Utilise autant que possible le même texte, la même langue et le même contexte pour pouvoir comparer les tests.

Ce que signifie le score

Taux de présencePart des tests terminés où le commerce est explicitement cité. Les tests « incertains » ne sont pas comptés comme des absences.
Position observéePosition indiquée manuellement dans la réponse lorsqu’il existe une liste clairement ordonnée. Ce n’est pas un classement universel de l’IA.
ConcurrentsLes noms souvent cités peuvent aider à repérer des sources, spécialités ou informations à renforcer, mais leur présence seule n’explique pas le classement.
Automatisation complètePour lancer les requêtes automatiquement, chaque fournisseur doit autoriser l’accès via une API adaptée et les identifiants doivent rester dans un backend sécurisé. Ils ne doivent jamais être inscrits dans le code public GitHub Pages.

À connaître

Le navigateur bloque généralement la lecture du HTML d’un autre site sans autorisation CORS. Les tests ci-dessous signalent donc les contrôles locaux faisables et proposent l’ouverture d’outils tiers pour les tests qui exigent un serveur d’analyse.
